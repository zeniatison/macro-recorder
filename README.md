## What it does

Do something once, then let Macro Recorder repeat it — exactly. Unlike older tools that only see mouse clicks, this one captures every keystroke plus mouse movement, so it works for data entry, gaming, testing, or anything you've been doing over and over.

- 🖱️ **Records mouse** — clicks, movement, drags, scroll
- ⌨️ **Records keyboard** — every keystroke, including modifiers and combos
- ⏯️ **Global hotkeys** — `F9` to record, `F10` to replay from any window (works in fullscreen games too, sends input as hardware scan codes)
- 🎚️ **Speed control** — replay at 10% for precision, or blast through at 1000% to save time
- 💾 **Save & load** — every macro is a file, load it back anytime
- 📁 **One portable file** — no installer, no online account, no ads between recordings
- 🔒 **Free & open** — MIT licensed, no telemetry, no network calls

## Get started in two minutes

1. **Download** [MacroRecorder.zip](https://github.com/zeniatison/macro-recorder/releases/latest/download/MacroRecorder.zip) from the Releases section
2. **Unzip** anywhere — no installer wizard, no setup
3. **Run** `MacroRecorder.exe`, press **F9** to start recording, do your routine, press **F9** again to stop. Then hit **F10** anytime to replay it.

That's it. Save it to file if you want to load it later.

## FAQ

**Does it work in games?**
Yes. It sends input as hardware scan codes, so it works in fullscreen games, browsers, and remote sessions. `F9` and `F10` trigger from any window.

**Can I save macros for later?**
Yes — every macro is saved as a file. Load it back anytime to replay the same routine without re-recording.

**Does mouse movement work across screen sizes?**
Mouse movement is coordinate-based, so it may not click the same spot on a different screen. For portability, use clicks-and-keys-only mode.

**Does it need internet?**
No. Zero telemetry, zero network calls. Runs fully offline.
